# Streamlined flight HUD

`streamlined-hud-reference.png` is the user-approved visual concept, generated with the built-in image tool from an actual game screenshot. It is a design reference, not a captured installed build.

The implementation keeps the space view open: a tabbed Nearby/Destinations/Group browser at upper left, scrollable communications with a persistent input at upper centre, contextual selected-target actions at upper right, and one flight/Systems strip below. Inventory and group management are contextual overlays. Secondary commands live in the strip's menu.

Preserve authoritative inventory/combat state, native icons, all 24 shortcut slots, ammo selection and reload preferences, target Assist, dragging, chat resizing, exact values on hover, and the combined 240-degree shield / 120-degree hull gauge with opposing fills. Reactor is amber; shield is blue; hull/danger is red. Empty controls and repeated explanatory labels should not occupy permanent flight space.
