# Proteron ship models

Five PBR ship models (`archimedes`, `dalton`, `hippocrates`, `pythagoras`, `watson`) are by Viktor Hahn and licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Source: [Proteron Ships on OpenGameArt](https://opengameart.org/content/proteron-ships), `obj.zip`, downloaded 2026-10-24. Source archive SHA-256: `a1d2742b1948a36d718686aabf865340c769cef4bc8d630e5b57c0b54afc06a7`.

The OBJ, MTL and texture files here are copied unchanged from that archive. The Unity `StylizedShip` shader maps the supplied diffuse, normal, metallic, roughness, and emission textures to the game's faction colors. Model scale and screen-based LOD are set in `SpaceArt.cs`; the older Viktor ship meshes serve as distant LODs.

Credit: **Viktor Hahn, “Proteron Ships,” CC BY 4.0**. Changes to presentation: material tinting, scale, and LOD selection in Unity. The source models themselves are unmodified.
