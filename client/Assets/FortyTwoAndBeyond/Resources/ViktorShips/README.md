# Textured spacecraft by Viktor Hahn

Corvette, frigate, destroyer, cruiser, and carrier OBJ meshes and their diffuse, normal, specular, and emission
maps are by **Viktor Hahn**. Source: https://opengameart.org/content/more-spaceships

License: Creative Commons Attribution 3.0 Unported
(https://creativecommons.org/licenses/by/3.0/). The artist's original attribution
statement is preserved in `LICENSE.txt`. The artwork is incorporated into the
Unity scene at runtime and its materials are configured in `SpaceArt.cs`.

Original archive: `spaceships2.zip`, SHA-256
`6f2c427656938dbfb7126d35de53f61b665f15a6a9b6f45e1da014b9f064b984`.
The five ship models are imported without modifying their mesh or texture bytes.
The Unity client maps selected native MOB asset IDs to these visual stand-ins;
they do not change server combat, collision, or identity.
