# Saturn backdrop texture

`SaturnNASA.jpg` is the unmodified 720 × 360 JPEG published by NASA 3D Resources:

- Asset: https://science.nasa.gov/3d-resources/saturn/
- Original file: https://assets.science.nasa.gov/content/dam/science/cds/3d/resources/image/saturn/Saturn.jpg
- Creator: Don Davis; owner: JPL/Caltech. The map is an illustrative, fictional rendering, as identified by NASA/JPL.
- Use guidance: https://www.nasa.gov/nasa-brand-center/images-and-media/ . NASA says its 3D Resource assets are free to download and use and asks that NASA be acknowledged as the source. This project does not imply NASA endorsement.
- SHA-256 of the original JPEG: `d959a239e3d87630daf08e2a688dcbf315fe01b1fd474e55522770108f40aca7`

The Unity planet shader retains its procedural fallback if this optional texture is unavailable.
