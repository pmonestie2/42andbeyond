# Defender Fold Space high tiers

The pinned `reference/cpp/trunk/Net7/PlayerSkills.h` and `PlayerClass.cpp` name Directional Teleport ability **36** and Area Teleport ability **17**. The archived `AFoldSpace` handler is absent. The [Net-7 Fold Space table](https://net7wiki.bmsite.net/index.php?title=Fold_Space) puts these at Defender ranks **6** and **7**: Directional Teleport moves one target **6,500** along its facing; Area Teleport moves group ships within **6,000** by **6,800** along the caster's facing. Explorer and Seeker cannot train beyond rank 5 in this skill. A `PlayerClass.cpp` comment calls Directional rank 5, conflicting with the public rank table and catalog; this implementation uses rank 6.

Native `0x58` activation uses ability 36 with a previously selected self, grouped pilot, or visible hostile MOB. Ability 17 selects the caster and includes eligible nearby group ships. Existing native cast effect **202**, teleport effect **267**, progress and cooldown packets are reused. World bounds clamp destinations. A selected MOB is pinned to its life generation and must remain hostile/visible/in range when the cast completes. A grouped pilot must remain eligible, in the same sector and session epoch. On a rank-seven cast, a frozen recipient list prevents joining or leaving pilots from changing a partially delivered plan.

The energy costs (**180/300**), **3-second** charge and **5-second** cooldown are local tuning because no executable handler or public numeric cost/timing was found. Directional pilot acquisition uses 6,000 range; hostile MOB acquisition uses 6,500 range. These are also local rules. Energy is charged at activation and is not refunded when a target leaves before completion, matching other charged abilities in this server.

The caster checkpoints its pending cast and frozen destination plan before any move. Each recipient checkpoints its new position and bounded receipt before the next recipient moves. A retry or resumed server skips an already settled recipient. MOB movement and its generation-pinned receipt persist in the shared combat world before the caster completes the cast. If one recipient becomes ineligible, the others can still arrive. Login/restart does not repeat a completed move. This is a per-recipient durable delivery, not a single atomic group teleport.

Disposable tests cover the rank-six peer and hostile MOB paths, wrong-class rejection, rank-seven group travel, a forced recipient checkpoint failure, retry without double movement, and server replacement. No live account or client was used.
