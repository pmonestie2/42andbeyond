# Progen Sentinel Power Down

Source: [Net-7 Power Down skill reference](https://net7wiki.bmsite.net/index.php?title=Power_Down). The archived `reference/cpp/trunk/Net7/PlayerClass.cpp` maps ability IDs 78, 1, 2, 3, and 4 to `APowerDown`, but its executable handler is absent from the pinned reference. The public reference supplies the energy costs, rank-specific recharge fractions, engine-off gate, indefinite toggle, three-second cooldown, hostile target suppression, and cancellation when warp, items, or weapons are activated.

The server accepts the usual native `0x58` ability request. It charges energy once and publishes an indefinite `ShipIndex.Buffs` slot 12 status named `Power_Down` through `0x1b`; ending the toggle clears the same slot. The active ability, reactor energy, and cooldown are committed together in the disposable session checkpoint and replayed after a short replacement. MOB target selection removes a powered-down pilot from sensor and hate eligibility, while already committed projectile hits remain valid. Turning in place is allowed; impulse thrust, follow, formation, warp, mounted item activation, and weapons end the toggle. Reactor and shield base recharge use the chosen tier's fraction while independent equipped bonuses remain additive.

The source does not provide numeric success probabilities for ranks 2/4 or for `SKILL_POWERDOWN` / `STAT_POWERDOWN` gear. The implementation suppresses hostile targeting deterministically while active, without inventing a random formula. A verified native visual descriptor is unavailable, so this implementation emits no `0x09` object effect. The `0x1b` buff name should be checked in the legacy client before claiming a specific icon or animation.
