# Equipped Rally skill

Equipped `SKILL_RALLY` modifiers raise the effective rank used by Rally's
critical rate, deflection, and weapon accuracy bonuses. The strongest equipped
modifier is used, capped at +3 ranks. The trained rank still determines which
tactics can be activated, group range, energy cost, and duration.

The bonus is frozen when the cast completes and stored in each recipient's
durable Rally buff. It survives server replacement and a partially delivered
group cast. Older stored buffs default to zero bonus. The potency slopes and
+3 cap are local tuning; the public item catalog supplies the modifier values.
