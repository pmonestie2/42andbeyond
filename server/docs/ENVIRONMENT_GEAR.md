# Equipped Environment Shield strength

The public catalog's equipped effect 50, **Improved Environment Shield**, carries `SKILL_ENVIRONMENT_SHIELD` operation 1 and a second duration value (`NO_STAT` operation 5). For example, Jenquai Reinforcer Model II Novem (item 5335) grants +3.33 skill levels and +20 seconds. The [Net-7 item entry](https://net7wiki.bmsite.net/index.php?title=Jenquai_Reinforcer_Model_II_Novem) confirms both values. The archived `AEnvironmentalShield` executable handler is absent, so the precise combat scaling per bonus level cannot be recovered here.

The server now selects the strongest intact equipped bonus (the same nonstacking operation rule as other gear), freezes it when the Explorer casts, and passes it to selected/group recipients. The second catalog value extends the existing 180-second duration. Skill tier unlocks and unlocked defense families remain based on trained rank. Local combat tuning adds 0.5 percentage points of mitigation, 10% more reflection capacity, and 0.5 percentage points of reactor feedback per equipped bonus level. These gains are bounded to five bonus levels; the public item values currently top out at +3.93. This scaling is a local approximation, while the skill and duration bonuses themselves are catalog-backed.

Recipient status, effective bonus, remaining duration, and visual identity are checkpointed before native status/effect packets are published. Expiry clears and checkpoints the bonus before removal packets. A retry after a recipient checkpoint failure restores its prior state and sends no success packet. The existing group coordinator still delivers Environment Shield as transient per-tick support; a crash between recipients may leave a partially buffed group. That cross-recipient atomicity remains a separate service migration.
