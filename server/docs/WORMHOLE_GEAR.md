# Equipped Wormhole Creation Time

The public catalog's `STAT_WORMHOLE_CREATION_TIME` modifier subtracts its
strongest intact equipped value from the three-second Wormhole charge. The
result has a local 0.25-second floor so a gate still has a visible cast. Gear
does not unlock destinations or ranks. The adjusted charge is frozen in the
cast when activation begins, so changing equipment while it charges does not
change the queued transition. Other ability timings are unaffected.
